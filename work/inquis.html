Background

This project began as a small expense-tracking script during my first year of college — the kind of project every beginner writes once. After revisiting the original codebase, I decided to rebuild it properly rather than let it sit as a dead first-year artifact. The redevelopment focused on usability, analytics depth, data visualization, and overall experience — moving from "records a number" to "tells you something useful about your spending." AI-assisted development tools were used during parts of the refactor and interface design.

What it does now

Expense management — add and track expenses, attach notes, backdate entries for historical record-keeping, delete individual transactions, clear all transactions with a confirmation safeguard.

Budget management — set monthly spending budgets, track remaining budget in real time, monitor budget utilization as a percentage.

Analytics dashboard — total spending overview, budget-tracking metrics, remaining-budget calculations, top spending category, and a financial health score.

Smart insights — spending-pattern summaries, budget-utilization insights, category-contribution analysis.

Visualization — an interactive spending-distribution pie chart, category-wise spending breakdown, and daily spending-trend view.

Version history

v2 Desktop application — Tkinter, SQLite, Matplotlib
v3 Web-based analytics platform — Streamlit, SQLite, Pandas, Plotly (current, deployed)

Keeping both versions documented was intentional — it's a more honest record of how the project actually got better than presenting only the finished state.

Tech stack & why

Streamlit again made sense here for the same reason it did on SearchLens: it gets a real interactive dashboard running from Python without hand-building a frontend, which matters more for a personal tool than a polished custom UI would. SQLite gives persistent storage without provisioning a server — appropriate for a single-user personal-finance tool where the entire dataset is one person's transaction history. Plotly handles the interactive charts (trend line, category donut, monthly bar chart, 7-day rolling average) that a static Matplotlib chart couldn't give the v3 rebuild.
